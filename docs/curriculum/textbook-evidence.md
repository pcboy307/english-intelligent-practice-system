## 可复现检查

1. 打开对应官方 URL，页面标题分别为：
   - `普通高中教科书·英语必修 第一册`
   - `普通高中教科书·英语必修 第二册`
   - `普通高中教科书·英语选择性必修 第二册`
2. URL 中的 `page` 参数分别为 `023`、`037`、`060`。
3. 未登录时可确认官方书目与页面定位；正文阅读由平台要求登录，因此不把登录提示页冒充教材正文截图。
4. 结构页无独占标题的语法项目不强行归到某个单元，另见 `grammar-id-ownership.md`。
