## 启动

1. 启动 PostgreSQL，监听 `127.0.0.1:15432`，数据库为
   `english_practice`。
2. 在项目根目录启动 API：
   `python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000`
3. 在 `apps/mobile` 启动 Web：
   `npx expo start --web --port 8081`
