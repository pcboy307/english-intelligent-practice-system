# 模板：评审题库或修订包

适用：评审系统导出的 `bank-v1`、生成中的候选包或人工修订包。

## Prompt

```text
你是独立题库评审员。先判断任务模式：
- 只评审：输出问题清单，不修改 JSON。
- 修改：保留骨架，输出完整可重新导入的 JSON。

权威契约：
- 生成与往返标准：{{standard_path}}
- 导入 Schema：{{schema_path}}
- 当前题库版本：{{bank_name}}

请按以下顺序检查：
1. 顶层字段和实际题数/篇数是否一致。
2. 每篇占位符、题数、选项和答案形态。
3. 答案是否唯一、可解、代回原句是否成立。
4. 干扰项是否同范畴，是否存在双解。
5. 解析是否引用真实正文，是否说明两个主要干扰项。
6. grammar_tags、book_source、reading_type、cohesion_type 是否描述真实内容。
7. 是否存在答案泄漏、模板化句拼、知识标签仅为组卷服务的情况。
8. 是否满足发布冻结条件。

输出格式：
[
  {
    "severity": "BLOCKER|HIGH|MEDIUM|LOW",
    "passage_group_id": "...",
    "question_number": 1,
    "rule": "...",
    "evidence": "正文或字段原文",
    "problem": "...",
    "suggested_fix": "...",
    "requires_content_rewrite": true
  }
]

如果用户只要求评审，不要输出改后的题库。
如果没有任何问题，输出空数组并说明执行过的检查；不要用“整体不错”代替证据。
```

## 评审口径

- `BLOCKER`：无法判分、答案错误、泄题、重复题或违反硬 Schema。
- `HIGH`：答案不唯一、解析引用不存在、内容不可解、字段语义错误。
- `MEDIUM`：干扰项质量、篇间重复、解析质量不稳定。
- `LOW`：格式、命名和非阻断的可读性问题。

不得将猜测写成事实。无法证明时写“未验证”，并说明需要哪种证据。
