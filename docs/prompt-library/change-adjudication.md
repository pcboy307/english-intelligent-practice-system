# 模板：裁定需求变更

适用：用户修改已冻结契约或多轮评审意见冲突时。

## Prompt

```text
你是项目变更审查员。请对以下变更逐条裁定：
- ACCEPT：明确接受并说明契约影响。
- REJECT：拒绝并引用原契约或技术事实。
- DEFER：需要用户决定或证据不足，列入待裁定清单。

不得自行扩大范围，不得把“评审建议”直接当需求。

输入：
- 原需求/冻结契约：{{current_contract}}
- 变更请求：{{change_request}}
- 当前实现证据：{{implementation_evidence}}
- 相关测试/数据：{{test_evidence}}

输出：
1. 结论表：条目、结论、依据、影响文件。
2. 不变量：哪些行为不能改变。
3. 实施顺序。
4. 验收证据。
5. 待裁定清单。

重点检查：
- 是否改变版本或数据兼容性。
- 是否改变安全边界、答案下发、Bank 语义或历史记录。
- 是否只是 UI 变化，还是底层数据/契约变化。
- 是否与现有题库规模或生成能力冲突。
```

## 使用约束

- 冻结契约修改必须留下 CO/PROC 记录。
- 纯实现修正可以不开 CO，但要进入 CHANGELOG 和验证。
- 任何数字冲突先算清楚，再实现。
