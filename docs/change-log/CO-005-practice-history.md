# CO-005：逐题导航、模型分析与历史报告

- 日期：2026-11-07
- 决定人：用户
- 版本：V11.3 → V11.4

## 练习页

- 由“一篇一页”改为“一题一页”。
- 上一题、下一题、交卷和查看报告集中在右上角。
- 未强制答完才能翻题；交卷前查看报告保持禁用。
- 交卷后仍可在逐题回顾中查看原题、我的选择和正误，不显示解析。

## 薄弱知识点分析

- 报告生成时把题目快照和作答结果发送给本地 `qwen-local` 模型。
- 模型返回不超过 100 字的中文分析，包含两个主要薄弱点、错因和当天可执行建议。
- 模型不可用时使用短中文回退文案，并在报告中标记 `weakness_analysis_source=fallback`。
- 报告页不再显示三条规则标签摘要，只显示这一段落和逐题解析。

## 历史报告

- 每份报告保存题目、选项、作答、正确答案、对错和解析快照。
- 标题格式：`日期-时间-题目数-分数`。
- 首页提供“历史报告”入口；历史列表支持打开和二次确认删除。
- 删除在单一数据库事务中同步删除报告、题目快照、作答和会话记录。
