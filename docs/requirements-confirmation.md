# 需求理解确认单（M0）

状态：冻结候选，等待系统所有者签字。

版本：以 `contracts/VERSION` 为唯一当前版本；本文不另设手写版本号。

## 1. 已纠偏

- 正式教学单元是 **25 个**：必修 1–3 共 15 个，选必 1–2 共 10 个；不存在“20 个教材白名单”口径。
- 词汇白名单第一层使用教育部《义务教育英语课程标准（2022年版）》附录 3 的 1600 项三级词汇表，不再用 ECDICT `zk` 近似。
- 官方基础层声明 1600 项；斜杠变体展开后为 1603 个单词头 + 4 个短语。官方补充数词、日期、地名、机构与节日表为 120 个单词头 + 44 个短语。
- 人教版已学新增层 1846 项；闭合功能词另补 5 项。
- 合并去重后为 **3021 个单词头**，另有 392 个短语，完整允许表 3413 项。
- 单词语篇校验使用 3021 个词头并按 lemma 匹配；短语单独精确匹配，不进入单词分母。
- 语法白名单按 grammar item ID 计数；25 个单元只是教材出处和题材对齐单位。
- 必修一 Welcome Unit 词汇纳入已学词汇；Welcome Unit 不计入 25 个正式教学单元。

## 2. 硬约束

### Bank

- 新生成必须创建新 Bank，禁止向已有 Bank 追加或覆盖。
- 同一时刻只有一个 `active` Bank。
- 会话创建时绑定 `bank_id`；切换只影响新会话。
- 历史会话、报告和错题永久可追溯原 Bank。
- 组卷绝不跨 Bank 混抽。
- 归档保留全部数据，默认不提供物理删除。

### 题库

- 标准 Bank：2000 题 / 315 篇，配比 600/400/700/300。
- Demo Bank：80 题 / 11 篇，配比 30/20/20/10。
- 全库难度：1 档 15% / 2 档 30% / 3 档 35% / 4 档 15% / 5 档 5%。
- 单套易（1–2 档）40% / 中（3 档）40% / 难（4–5 档）20%。
- 难档可在满足条件时提至 25%，基础下限 15%；单套 5 档题最多 3 题且不集中同一篇。
- 考点册次：选必二 45% / 选必一 30% / 必修 20% / 跨册 5%。
- 阅读与七选五中，选必一+选必二话题合计不少于 50%。
- 生词率不超过 3%；每篇最多 2 个非白名单词，必须有中文释义且不得作考点。
- 阅读 ≤250 词、七选五 ≤220 词、完型 ≤220 词、语法填空 ≤180 词。
- 生成 job 单批 ≤10 篇；首批完成后强制暂停；全量 job 单独批准。

### 练习与错题

- 组卷使用完整双通道公式与全部约束，禁止纯随机。
- 同一错题必须在两次不同会话都答对才能消标；同套重复不计。
- 换库后旧题 `I_err` 失效；`S_kp`、`G_gap` 与知识点掌握度跨库继承。
- 错题 `streak` 换库冻结，换回原库继续。
- 交卷前 API 和 App 持久化均不得包含答案或解析。
- 服务端 deadline 是计时权威；回前台重新校准。

### 报告

- 单次报告：总分、得分率、用时、四题型得分率、逐题结果、知识点三档、薄弱 Top3、绑定知识点的具体建议。
- 阶段报告：练习次数、平均正确率、总题量、四题型趋势、斜率、EWMA 矩阵、已消除/活跃错题、标准差、结论和 4 周行动清单。
- 阶段报告区间跨 Bank 时必须输出“跨题库说明”：原题错题加权失效，知识点缺口跨库继承。
- 阶段报告是 M2 正式交付，不属于永久可删项。

### App 与数据

- 页面：首页、练习页、报告页；逐题解析并入报告页，报告可跳回原题回顾。
- 当前版本运行载体为 Expo Web（`react-native-web`）；保留 React Native + Expo 源码，手机真机验收推迟。
- 首页只读显示当前题库名称，App 不允许切换 Bank。
- App 设置页必须支持数据清除：二次确认后清本地缓存并删除后端该 `device_student_id` 全部数据。
- 主按钮固定黑底白字；强调色绝不作按钮底色。
- 不做登录、云同步、教师端、家长端、暗色模式。
- 视觉只读 `contracts/design-tokens.json`；白底黑字、无渐变、无阴影、无插画、圆角 ≤14、字号 ≥13。
- 后端监听 `0.0.0.0`，学生端局域网可达；`/admin/*` 只接受 socket 回环地址并通过 `X-Admin-Token` 鉴权。
- 生成审批必须落库；审核请求必须携带 `bank_id` 并校验题目归属；交卷必须携带幂等键。
- Web 端 `device_student_id` 使用 localStorage，属于本地演示的安全等级降级；回到手机端必须换回原生 secure store。
- Web 布局在 `<768px` 时最大宽度 480px，桌面端内容区最大宽度 960px，正文块 760px；CSS 强制 `color-scheme: light`。
- 语法填空为语篇内 ①–⑩ 加语篇后四选一，禁止手输；组卷按篇和题号排序，前端按篇分节。
- 报告与已交卷回顾双向跳转；回顾只显示原题、我的选择和对错，解析只在报告页。
- 练习页逐题展示；上一题、下一题、查看报告和交卷集中在右上角。
- 薄弱知识点由大模型结合题目与作答结果分析，返回不超过 300 字的中文建议。
- 每次报告的题目、选项、作答、对错和解析作为快照持久化；历史报告按 `日期-时间-题目数-分数` 命名，并可打开或事务化删除。

## 3. M1 豁免与延期

- Demo Bank 为 80 题，M1 允许同题重复。
- “7 天内同题重复率 <10%”不在 M1 验收，M3 生效。
- 不因此削弱 Bank 隔离、组卷权重、错题机制、答案安全或服务端计时。
- 所有延期项见 `docs/待补齐清单.md`。

## 4. 25 单元与白名单口径

| 维度 | 计数方式 | 事实源 |
|---|---|---|
| 正式教学单元 | 25 个 | `contracts/curriculum.json.units` |
| 词汇 | 去重词元 | `contracts/vocabulary-whitelist.json.entries` |
| 语法 | grammar item ID | `contracts/curriculum.json.grammar_whitelist` |
| 题材 | 25 个正式单元题材 | `contracts/curriculum.json.units[].topic` |
| 组卷册次 | 必修/选必一/选必二/跨册占比 | `config/practice-modes.json.paper_constraints` |

词汇来源为两层合并：

1. 教育部 2022 版课标三级词汇表 1600 项，快照在 `contracts/vocabulary/kebiao-2022-level3.json`。
2. 人教版 2019 必修 1–3、选择性必修 1–2 的 1846 个去重新增词头；必修一 Welcome Unit 包含在词汇范围内。

派生词不自动视为已学；若来源词表未列出，必须由已批准构词规则接受。复数、过去式、过去分词、现在分词、第三人称单数、比较级和最高级在运行时还原到基础词头匹配，不另计白名单数量。此前 1967 项仅为高中教材新增词表，缺少义务教育基础层，会把 `able`、`afraid`、`accept` 等初中已学词误判为超纲，已修正。

ECDICT `zk` 仅保留为差异审计参照。与官方三级词表比对：交集 1326，并集 1880，Jaccard 差异率 **29.47%**，因此不得作为生产白名单。

本表按教材词表口径（教材实际列出的词）统计，宽于课标最低要求，生词率判定偏宽松；超纲校验以“高阶难词抽检被排除”和“语法标签全部在白名单”为准，不以生词率单指标判定。

## 5. M1 交付节点

1. Docker Compose 启动 PostgreSQL、Redis、FastAPI。
2. 浏览器访问 Expo Web 页面，能完成一套 30 分钟练习并看到报告；首页显示 active Bank 名称。
3. Demo Bank 80 题 / 11 篇通过自动校验。
4. 30 分钟出 29/30 题，60 分钟出 42 题。
5. 交卷报告和逐题解析完整。
6. 错题加权、两次不同会话消标完整。
7. 服务端计时、切后台校准、断网恢复答案。
8. 未交卷接口和缓存均无答案字段。
9. 四页面视觉截图与 design tokens 比对。
10. 按 `contracts/VERSION` 指向的当前版本验收 1–11 条并逐项附证据，无法执行项写 `N/A + 原因`。

原“真机 App 能连后端”推迟到手机端阶段，不作为本期门禁。
