# 提示词模板库（可复用）

> 来源说明：本项目的最终路线是手写，云端 LLM 管线只跑到 M2。因此这里收录的模板分两类——
> **A 类**是从 M2 实际管线（`scripts/run-m2-full.py`、`backend/app/generation.py`）与评审返回中重建的可运行模板；
> **B 类**是从 12 批手写中总结出的「写作规格卡」，可直接作为 LLM 提示词或人工写作规范。
> 所有模板都标注了它防的是哪个具体坑。

---

## 0. 通用原则（先读这六条，模板才有意义）

| # | 原则 | 防的坑 |
|---|---|---|
| 1 | **一次只生成一篇**，绝不要求一次多篇 | 输出截断、解析编造、干扰项荒诞 |
| 2 | 结构化输出用 `json_object`，不用 `json_schema` | DeepSeek 对 `json_schema` 返 HTTP 400 |
| 3 | 结构校验失败先查 `finish_reason` | 把截断误判为"模型不会写" |
| 4 | 把可机械验证的数字写进提示（词数、句长、Flesch、空位数） | 靠"写得好一点"这种话调指标 |
| 5 | 答案位置、题材名、册次这些**枚举型字段**要在提示里给出闭集 | 自由发挥后无法导入 |
| 6 | 提示末尾附自检清单，要求模型输出前逐条打勾 | 模型不知道哪些会被判失败 |

## 1. A 类：单篇生成模板

### 1.1 完形填空（M2.6 参数）

```text
你是中国高中英语命题人。为「广东重点高中高二周测」难度命制一篇完形填空。

【硬参数】
- 正文 280–320 词（含空位标记 (1) ______ 至 (15) ______，各出现一次）
- 平均句长 ≥15 词；至少 4 个句子长度 ≥25 词
- Flesch Reading Ease 45–60
- 题材：{{topic}}（必须从以下 15 项中选：科技/环境/健康心理/文化艺术/旅行地理/志愿公益/
  职业创业/家庭代际/体育竞技/社会伦理/人物传记/自然科普/历史遗产/媒体信息/城市交通）
- 至少包含「非谓语 / 名词性从句 / 插入语或同位语 / 倒装或省略」中的 3 类结构
- 至少 3 道近义辨析题（同空四选项语义接近，靠上下文线索区分）

【硬约束（会被机器校验，违反即驳回）】
1. 每个空 4 个选项：同一词类、同一形态层级、互不重复。
2. 正确答案及其 exact 形式、不规则屈折、规则屈折后缀，在**整篇正文中出现次数必须为 0**
   （派生词不算泄漏：achieve→achievement 允许；achieve→achieved 不允许）。
3. 正确选项不得固定放在第一个位置；每题自行决定顺序，15 个空的正确项应大致均匀分布。
4. 不允许只考词形变化；不允许四个选项语义场完全不同（那不是辨析，是凑数）。
5. 语篇必须是一个连贯故事或说明，不能是互不相关的句子拼接。

【输出 JSON（单篇）】
{"validation_profile":"m26","type":"cloze","passage_group_id":"{{id}}","topic":"{{topic}}",
 "book_source":"{{book}}","difficulty":{{d}},"word_count":{{wc}},"flesch_reading_ease":{{f}},
 "passage":"...","questions":[
   {"number":1,"stem":"选择第 (1) 空最合适的选项。","options":["a","b","c","d"],"answer":"a",
    "explanation":"中文≥3句；说明依据；点名两个干扰项（用 A/B/C/D 项 + 其文字）",
    "knowledge_points":["..."],"grammar_tags":["noun_clauses"],"book_source":"{{book}}",
    "difficulty":{{qd}},
    "near_synonym_calibration":true,"context_clue":"...","clue_argument":"..."}
 ]}
```

> `grammar_tags` 只用 `noun_clauses` / `tense_system` / `word_formation` 三个之一（全册可用，天然满足册次交集），**不要为过校验改 `book_source`**。

### 1.2 语法填空（10 空）

```text
【硬参数】
- 正文 220–260 词；空位用单圈码 ① ______ 至 ⑩ ______，按顺序各出现一次（不要写成 （①））
- 10 题中必须同时出现以下五类，各至少 1 题：
  non_finite_perfect_passive / preposition_plus_which / what_noun_clause / subjunctive / inversion
- 每题四个选项属于同一语法范畴（例如全是关系词短语、全是谓语形式）

【硬约束】
1. 答案代回后整句必须语法成立、语义自然（主谓一致、及物性、可数性、介词搭配、时态语态、非谓语关系）。
2. 每个空只能有一个最佳答案；若两个选项都能成立，改写句子而不是硬选。
3. 题级 book_source 必须落在该题全部 grammar_tags 允许册次的交集内：
   partial_inversion_basic 只能选必二；passive_voice_tenses 只能必修/选必二；
   subjunctive_* 只能选必一/选必二/跨册；relative_clauses_defining、adverbial_clauses、
   subject_verb_agreement、articles、prepositions、pronouns、conjunctions、
   comparatives_superlatives、infinitive_nonfinite 只能必修。
```

> 语法填空**不设 Flesch 门禁**，不要为了 Flesch 改语法篇；这道门禁只对完形与阅读生效。

### 1.3 阅读理解（4 题）

```text
【硬参数】
- 正文 350–420 词；平均句长 ≥20 词；Flesch 45–60
- 正好 4 题，四题 reading_type 互不相同，必须含 1 题 paragraph_function
- 高阶（main_idea / inference / vocabulary_in_context / purpose_or_attitude / paragraph_function）≥3 题
- 允许 reading_type：main_idea detail inference vocabulary_in_context purpose_or_attitude paragraph_function

【硬约束】
1. evidence_sentence 必须逐字符出现在正文里（复制原文，不改标点、不改大小写）。
2. 正确答案不得与正文连续重合 ≥5 个单词。
3. 禁止元语言题（"哪一句包含某语法结构"）。
4. 不得出现「第四段中划线词」而正文没有下划线——改成 `What does "handles" most nearly mean in the fourth paragraph?`
5. 词汇题四个选项必须是同一词性、可替换同一位置的词。
```

### 1.4 七选五（5 空）

```text
【硬参数】
- 正文 320–380 词；说明文或议论文，主题具有抽象性
- 篇级 options 必须正好 A–G 七个互不重复的完整句
- 每题 options 与篇级完全一致；answer 是单字母
- 单篇 cohesion_type ≥3 种：pronoun_reference / logical_connector / lexical_repetition /
  semantic_contrast / time_order / general_to_specific

【硬约束】
1. 五个空不能都靠句首连接词（However / For example / Over time）就能锁定——
   至少要有 2 个空必须读到前一句的主语或名词才能选。
2. 干扰项必须与正确项在衔接手段上"看起来一样"（同样以连接词开头），真正区别在语义指向。
```

### 1.5 修订轮（校验器打回后的第二轮）

```text
你上一版被校验器拒绝，原因如下（逐条对应）：

{{violations}}

只修改被点名的位置，其余内容一字不改。修改后必须满足：
- 若改了正文任何词，同步更新 evidence_sentence 和解析中引用的原文；
- 若改了选项顺序，同步更新解析中所有「X 项」的字母；
- 修改后重新自检：词数、平均句长、Flesch、空位数、答案是否泄漏。
输出完整 JSON，不要只给 diff。
```

> 这条模板对应项目里最贵的一课：**改正文必须同步改 evidence_sentence 与解析引文**，否则报 `CITATION_NOT_FOUND`。

## 2. B 类：写作规格卡（人工手写也用）

### 2.1 每篇落笔前的六问

1. 这篇讲什么行业/场景？（必须与已写 71 篇不重复，且在 15 类题材内）
2. 主角是谁？（不是学生、不是老师——这是用户明确反馈的痛点）
3. 有没有一个具体数字或制度细节能撑起信息密度？（如"十四艘渔船自销五分之一""十二人持股的面包店贴出全部账目"）
4. 冲突点在哪？（重点校的难度来自"看起来都行、只有一个更贴"，不来自生词）
5. 15 个空里，哪 3–4 个是近义辨析？
6. 这篇的 Flesch 目标是多少？如果初稿超标，用哪三招降？（换音节更密的词 / 合并句号 / 加多音节抽象名词）

### 2.2 解析的统一写法

```text
第一句：答案依据（引原文关键词，指出线索）。
第二、三句：点名两个主要干扰项，用「A 项 xxx 表示……，但原文……，因此不成立」的句式。
最后一句（可选）：这道题考的是什么能力（推断 / 指代 / 态度）。
```

**禁止**：只写"其余选项不符合语境"；用"第二个选项"这种说法而不用 A–D 字母（校验器不认）。

### 2.3 干扰项设计的四条硬规矩

1. 同词性、同形态（四个都是动词过去式，或四个都是名词单数）。
2. 至少两个干扰项要"在别的语境里是对的"——只错在本题的搭配或指代。
3. 不能有三个语义场完全不同的选项（那是送分题）。
4. 正确项不得是唯一最长的选项（会被"选最长的"破解）。

### 2.4 难度校准的参照系

| 指标 | 达标值 | 常见偏差 |
|---|---|---|
| 完形词数 | 280–320 | 初稿常 299–320，容易贴上限 |
| 完形平均句长 | ≥15 | 大量短句 → 必须合并句号 |
| 完形长句（≥25 词） | ≥4 | 数之前先按 `(?<=[.!?])\s+` 切句 |
| 阅读词数 | 350–420 | 初稿常 296–347，普遍偏短 |
| 阅读平均句长 | ≥20 | 补词补成短句会把 Flesch 抬高 |
| Flesch | 45–60（仅完形/阅读） | 59 以上就要准备改 |

## 3. 反面模板（这些写法本项目验证过会出事）

| 反面写法 | 实际后果 |
|---|---|
| "一次生成 72 篇，每篇 15 题" | 输出截断、解析编造引文、干扰项荒诞（Codex 那批已演示） |
| "把题目出得难一点" | 无法执行；必须给出词数/句长/Flesch/结构四类硬参数 |
| "四个选项中有一个最佳答案" | 逼出平庸题；应改为"是否存在明显更优答案" |
| "先写一篇好文章，再从里面挖空" | 区分度救不回来——好文章的挖空点往往没有辨析空间 |
| "调提示词直到通过，再报成功率" | 成功率失真；必须按含失败请求的真实口径报 |
| "校验通过就算完成" | 450/460 答案在 A 位就是这样漏过去的 |
| 让生成模型自己写 `validation.json` 的语义结论 | `semantic_grammar_tag_mapping: 53/53` 是假的 |
| 解析里写"第二个选项/第三个选项" | 机器无法识别为点名干扰项，会持续报 `EXPLANATION_NO_DISTRACTOR` |

## 5. 复用方式

1. **人写**：用 §2 的规格卡 + §2.2 解析模板 + §3 反面清单。
2. **机器生成**：用 §1 的单篇模板，一次一篇，每篇跑校验器。
3. **交给 Agent**：把 03 号 Skill 草案装上，Agent 会按这套流程自检。
